# Python Bash Command Application

This application provides a simple user interface to display a list of predefined bash commands. Users can execute these commands directly from the application by clicking the corresponding buttons.

## Project Structure

```
python-bash-command-app
├── src
│   ├── terminal.py            # Manages the user interface
│   └─── commands.py      # Contains predefined bash commands
├── requirements.txt      # Lists the dependencies
└── README.md             # Documentation for the project
```

## Requirements

To run this application, you need to install the required dependencies. You can do this by running:

```
pip install -r requirements.txt
```

## Running the Application

To start the application, navigate to the `src` directory and run the following command:

```
python main.py
```

## Usage

Once the application is running, a window will appear displaying a list of bash commands. Click on the button next to a command to execute it in the terminal.
